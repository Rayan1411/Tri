# منصة الأسهم الأمريكية — شخصية

منصة بأسلوب TradingView للأسهم الأمريكية والعملات الرقمية (عبر Alpaca)، لمستخدم واحد، واجهة عربية RTL.

## ما الموجود (المرحلة الأولى)

| الميزة | التفاصيل |
|---|---|
| تسجيل الدخول | مستخدم واحد، كلمة المرور من متغيرات البيئة، جلسة بكوكي HttpOnly |
| الشارت | شموع خضراء/حمراء فقط (بدون مؤشرات)، أطر 1د/5د/15د/ساعة/يوم، تحديث كل 10 ثوانٍ، توقيت نيويورك |
| لوحة التحكم | قائمة المتابعة + الشارت (تحديث كل 10 ث) |
| صفحة السهم | الشارت، السعر، دردشة الذكاء الاصطناعي، إضافة/إزالة من المتابعة |
| البحث | بالرمز أو اسم الشركة |
| التنبيهات | فوق/تحت سعر، يفحصها الخادم كل 30 ثانية وتظهر في صفحة التنبيهات |
| المحفظة | حساب Alpaca Paper: المراكز والأوامر وإرسال/إلغاء أمر وإغلاق مركز |
| دردشة الذكاء الاصطناعي | تعمل بـ Google Gemini: تحلل الرمز المفتوح (سعر + شموع + أخبار) وتجيب بالعربية، وتقترح خطة تداول (دخول/أهداف/وقف) عند الطلب فقط. تعمل بمجرد إضافة `GEMINI_API_KEY` |

## الهيكل

```
backend/    FastAPI + SQLAlchemy (Postgres على Render، SQLite محليًا)
frontend/   Next.js 14 + TypeScript + Tailwind + Lightweight Charts
render.yaml نشر الخدمتين وقاعدة البيانات دفعة واحدة
```

الواجهة تمرّر كل `/api/*` إلى الخادم، فالمتصفح يتعامل مع عنوان واحد (لا CORS ولا مشاكل كوكيز).

## تشغيل محلي

```bash
# 1) الخادم
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # ثم عبّئ القيم (يجب تحميلها في البيئة، مثال أدناه)
export $(grep -v '^#' .env | xargs)
uvicorn app.main:app --reload --port 8000

# 2) الواجهة (طرفية ثانية)
cd frontend
npm install
npm run dev                 # http://localhost:3000
```

## النشر على Render

1. ارفع المجلد كاملًا إلى مستودع GitHub.
2. في Render: **New → Blueprint** واختر المستودع. سيقرأ `render.yaml` وينشئ: قاعدة `stocks-db` + الخادم `stocks-api` + الواجهة `stocks-web`.
3. عند الطلب أدخل القيم السرية للخادم `stocks-api`:
   - `APP_PASSWORD` — كلمة مرور دخولك
   - `ALPACA_KEY_ID` و `ALPACA_SECRET_KEY` — مفاتيح حساب Alpaca (Paper)
   - `GEMINI_API_KEY` — مفتاح Google AI Studio لتفعيل الدردشة
4. افتح رابط `stocks-web` وسجّل الدخول بـ `rayan` وكلمة المرور.

## متغيرات البيئة (الخادم)

| المتغير | الوصف |
|---|---|
| `APP_USERNAME` / `APP_PASSWORD` | بيانات الدخول (الافتراضي `rayan`) |
| `SECRET_KEY` | توقيع الجلسات (يُولَّد تلقائيًا على Render؛ لا تتركه على القيمة الافتراضية) |
| `ALPACA_KEY_ID` / `ALPACA_SECRET_KEY` | مفاتيح Alpaca |
| `ALPACA_FEED` | `iex` للخطة المجانية، `sip` بعد الاشتراك في Algo Trader Plus |
| `ALPACA_TRADING_URL` | الافتراضي حساب تجريبي `https://paper-api.alpaca.markets` |
| `GEMINI_API_KEY` / `AI_MODEL` | مفتاح Gemini واسم النموذج (الافتراضي `gemini-2.5-flash`) |
| `COOKIE_SECURE` | `true` على Render (مضبوط في `render.yaml`) |

## ملاحظات مهمة

- **الخطة المجانية في Render:** الخدمات تنام بعد فترة خمول (أول طلب بعدها يتأخر قليلًا)، والتنبيهات لا تُفحص وهي نائمة، وقاعدة Postgres المجانية تُحذف بعد 30 يومًا. للاستخدام اليومي رقِّ قاعدة البيانات والخادم إلى خطة مدفوعة من لوحة Render.
- **بيانات Alpaca المجانية (`iex`):** أسعار IEX وحدها، وهي جزء من حجم السوق الكلي، فقد تختلف الأرقام قليلًا عن TradingView. للتغطية الكاملة اشترك في Algo Trader Plus (99$/شهر) وغيّر `ALPACA_FEED=sip`.
- **التحديث اللحظي:** يعتمد على استعلام دوري كل 5–10 ثوانٍ وليس WebSocket، وهو كافٍ للاستخدام الشخصي. ترقيته لـ WebSocket ممكنة لاحقًا دون تغيير بقية الموقع.
- **التداول:** مربوط بحساب Paper افتراضيًا ويظهر ذلك بشارة في صفحة المحفظة. إن غيّرت `ALPACA_TRADING_URL` لحساب حقيقي ستظهر شارة تحذير حمراء، فاحرص على ما تفعله.
- **الذكاء الاصطناعي:** المنطق كله في `backend/app/ai.py` (السياق + الاستدعاء)، ويمكنك تبديل المزوّد أو تطوير التحليل هناك دون لمس الواجهة.
- شعار TradingView الصغير أسفل الشارت مطلوب بترخيص مكتبة Lightweight Charts، فلا تُزِله.
